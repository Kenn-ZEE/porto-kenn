# Portofolio Raka Raditya

Portofolio pribadi yang dibuat dengan HTML, CSS, dan JavaScript murni. Tidak memerlukan framework atau proses build.

## Menjalankan

Buka `index.html` di browser.

## Fitur

- Tampilan responsif untuk desktop dan ponsel
- Tema otomatis, terang, dan gelap
- Aksen RGB yang berubah setiap 4 detik
- Ringkasan keahlian, proyek, pendidikan, dan kontak
- Tombol email yang membuka Gmail

Foto profil di situs menggunakan preview beresolusi rendah.
